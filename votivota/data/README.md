# VOTIVOTA — Données électorales

Ce répertoire est réservé à la publication des données électorales de VOTIVOTA.

Les fichiers manifest.json, candidatures.json et calendrier.json seront publiés ici après validation et signature.

Aucune donnée personnelle des utilisateurs n'est collectée.

La clé privée de signature ne doit jamais être déposée dans ce répertoire.
